# Живая Казань

Прототип городской симуляции в духе The Sims на карте реального центра Казани: улицы, дома, остановки и маршруты транспорта из OpenStreetMap, жители‑боты, автобусы по настоящим маршрутам, полиция, скорая, ДТП и живые диалоги с жителями.

## Как устроено

| Папка | Что внутри |
|---|---|
| `site/zhivaya-kazan.html` | Разметка, стили, HUD, модальные окна |
| `site/js/` | Движок по модулям: `rally` (Кремль, площади, митинги, концерты), `talk` (разговор вслух между игроками и с жителями), `companion` (житель выполняет договорённость: идёт с игроком, ведёт в место, заходит внутрь), `transport` (маршрут 🧭: пешком, автобус с пересадкой «сесть/выйти», такси со счётчиком), `world` (граф, A*, переходы), `agents` (жители, машины, транспорт, ДТП), `vehicles` (самокат, каршеринг, своя машина, вождение), `interior` (интерьеры), `render` (2.5D-отрисовка), `main` (игрок, ввод, диалоги, цикл) |
| `site/js/net.js`, `site/js/chat.js` | Сеть (комната claude.ai или свой сервер `api.php`) и панель чата: Рядом · Город · Личные |
| `server/api.php`, `server/config.sample.php` | Мини-сервер для своего хостинга (PHP 7.4+): игроки онлайн, общий и личный чат, ответы жителей через OpenAI-совместимый API |
| `tools/build_deploy.py` | Сборка `deploy/kazan/` и `kazan.zip` для заливки на сайт |
| `tools/dev_build.py`, `tools/smoke_test.py` | Локальная сборка и прогон в headless Chromium |
| `site/kazan.json` | Карта центра (≈4,4×4,2 км): дороги с графом, здания, парки, вода, остановки, POI, маршруты. Генерируется из OSM |
| `tools/fetch_tiles.py` | Загрузка OSM плитками 3×3 с перебором зеркал Overpass (`--extras` — докачать стены Кремля и площади) |
| `tools/build_map.py` | Превращает сырые данные в компактный `site/kazan.json` (локальные метры × 10, стыковка маршрутов, обрезка воды) |

Страница не тянет ничего из сети — все данные лежат рядом в `kazan.json`.

## Пересобрать карту

```bash
python3 tools/fetch_tiles.py raw/kazan_big.json   # bbox задаётся внутри скрипта
python3 tools/build_map.py raw/kazan_big.json site/kazan.json
```

## Управление

- `WASD` / стрелки — идти, `Shift` — бежать, клик по карте — пойти туда
- `E` — действие: поговорить, зайти в кафе, сесть в автобус
- колесо мыши — масштаб, перетаскивание мышью — двигать карту, `◎` — вернуться к себе
- `🧭` — маршрут: выбрать место (поиск или клик по карте) и как ехать — пешком, автобусом или на такси
- `Enter` / `💬` — чат: Рядом (вслух), Город, Личные
- `Esc` — закрыть окно
- на телефоне: джойстик слева, кнопка действия внизу

## ДТП

На место едут ГИБДД и скорая (с мигалкой им можно против одностороннего движения). Полиция оттаскивает пострадавшего на тротуар и убирает машины к обочине, инспектор отчитывает и штрафует за переход не по зебре (500 ₽, ст. 12.29 КоАП) или оформляет выплату по ОСАГО, если сбили на переходе. Скорая в большинстве случаев лечит на месте — человек идёт дальше по своим делам, в тяжёлых случаях везёт в больницу.

## Выложить на свой сайт

```bash
python3 tools/build_deploy.py      # → deploy/kazan.zip
```

Распакуйте `kazan.zip` в корень сайта (получится папка `kazan/`). Нужен PHP 7.4+ с curl. Чтобы жители отвечали «своими словами», скопируйте `config.sample.php` в `config.php` и впишите ключ API (с российского хостинга — через прокси-сервис, адрес в `api_base`). Папка `kazan/data/` должна быть доступна PHP на запись.
