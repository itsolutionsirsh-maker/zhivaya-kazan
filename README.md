# Живая Казань

Прототип городской симуляции в духе The Sims на карте реального центра Казани: улицы, дома, остановки и маршруты транспорта из OpenStreetMap, жители‑боты, автобусы по настоящим маршрутам, полиция, скорая, ДТП и живые диалоги с жителями.

## Как устроено

| Папка | Что внутри |
|---|---|
| `site/zhivaya-kazan.html` | Разметка, стили, HUD, модальные окна |
| `site/js/` | Движок по модулям: `rally` (Кремль, площади, митинги, концерты), `talk` (разговор вслух между игроками и с жителями), `companion` (житель выполняет договорённость: идёт с игроком, ведёт в место, заходит внутрь), `transport` (маршрут 🧭: пешком, автобус с пересадкой «сесть/выйти», такси со счётчиком), `situations` + `sit-*.js` (жизненные ситуации, см. ниже), `drunk` (опьянение), `world` (граф, A*, переходы), `agents` (жители, машины, транспорт, ДТП), `vehicles` (самокат, каршеринг, своя машина, вождение), `interior` (интерьеры), `render` (2.5D-отрисовка), `main` (игрок, ввод, диалоги, цикл) |
| `site/js/net.js`, `site/js/chat.js` | Сеть (комната claude.ai или свой сервер `api.php`) и панель чата: Рядом · Город · Личные |
| `server/api.php`, `server/config.sample.php` | Мини-сервер для обычного хостинга (PHP 7.4+): игроки онлайн, общий и личный чат, ответы жителей через OpenAI-совместимый API |
| `server/node/` | Сервер для VPS (Node.js + WebSocket): онлайн в реальном времени, аккаунты и сохранения, установка одной командой |
| `tools/build_deploy.py` | Сборка `deploy/kazan/` и `kazan.zip` для заливки на сайт |
| `tools/dev_build.py`, `tools/smoke_test.py` | Локальная сборка и прогон в headless Chromium |
| `site/kazan.json` | Карта центра (≈4,4×4,2 км): дороги с графом, здания, парки, вода, остановки, POI, маршруты. Генерируется из OSM |
| `tools/fetch_tiles.py` | Загрузка OSM плитками 3×3 с перебором зеркал Overpass (`--extras` — докачать стены Кремля и площади) |
| `tools/build_map.py` | Превращает сырые данные в компактный `site/kazan.json` (локальные метры × 10, стыковка маршрутов, обрезка воды) |

Страница не тянет ничего из сети — все данные лежат рядом в `kazan.json`.

## Пересобрать карту

```bash
python3 tools/fetch_tiles.py raw/kazan_big.json   # bbox задаётся внутри скрипта
python3 tools/build_map.py raw/kazan_big.json site/kazan.json
```

## Управление

- `WASD` / стрелки — идти, `Shift` — бежать, клик по карте — пойти туда
- `E` — действие: поговорить, зайти в кафе, сесть в автобус
- колесо мыши — масштаб, перетаскивание мышью — двигать карту, `◎` — вернуться к себе
- `🧭` — маршрут: выбрать место (поиск или клик по карте) и как ехать — пешком, автобусом или на такси
- `Enter` / `💬` — чат: Рядом (вслух), Город, Личные
- `Esc` — закрыть окно
- на телефоне: джойстик слева, кнопка действия внизу

## ДТП

На место едут ГИБДД и скорая (с мигалкой им можно против одностороннего движения). Полиция оттаскивает пострадавшего на тротуар и убирает машины к обочине, инспектор отчитывает и штрафует за переход не по зебре (500 ₽, ст. 12.29 КоАП) или оформляет выплату по ОСАГО, если сбили на переходе. Скорая в большинстве случаев лечит на месте — человек идёт дальше по своим делам, в тяжёлых случаях везёт в больницу.

## Кафе, бар и последствия

В кафе и баре есть меню; со спутником можно сесть за один столик и угостить его. Пиво и настойка пьянят (`site/js/drunk.js`): героя шатает, он сам выкрикивает на прохожих, за руль нельзя. Бармен выставляет буяна, прохожие вызывают полицию — ночь в отделе, штраф по ст. 20.21 КоАП.

## Ситуации (жизненные случаи)

Один формат на все случаи — движок `site/js/situations.js`. Ситуация описывается одним объектом и регистрируется через `defSit`:

```js
defSit('wallet', {
  title: 'Кошелёк', auto: true, weight: 2, cool: 600,   // случайный запуск: вес и пауза до повтора (с)
  when()   { return scene === 'city' && !player.vehicle; },  // где и когда может случиться
  start(s) { /* участники, метки, карточка */ return true; }, // false — не получилось, ничего не запускаем
  update(s, dt) { /* каждый кадр; endSit(s) — конец */ },
  action(s) { return near ? {label: 'Поднять кошелёк', run} : null; },  // кнопка E на улице
  actionInside(s) { /* кнопка E в помещении */ },
  draw(s, toS, z) { /* своё рисование на карте */ },
  ctx(s, w) { return 'Ты только что потерял кошелёк…'; },   // подсказка жителю с ИИ, если с ним заговорить
});
```

Готовые помощники:

| Что | Функция |
|---|---|
| Карточка с 2–3 ходами (клавиши 1–3) | `sitCard({s, icon, title, text, choices:[{t, run, primary}], ttl, onTimeout, tone:'alert'\|'good'\|'call'})` |
| Последствия | `sitMoney(±₽, 'за что')`, `sitRep(±, 'за что')`, `sitMood(±)`, `dossier('запись в полиции')`, `remember(житель, 'что он запомнит')` |
| Отложенное последствие | счётчик в `s` и проверка в `update` (пример — «Оставить кошелёк себе» → звонок участкового через 1,5–3 мин) |
| Участники | `findWalker(minR, maxR)`, `takeActor(s, w)` (житель занят ситуацией), `moveActor(w, x, y, скорость)` + `stepActor(w, dt)`, `faceTo`, `say(w, 'реплика')` |
| Метки на карте | `mark(s, key, x, y, '🙋', 'подпись', {arrow:true})`, `unmark(key)` |
| Полиция | `callPatrol({x, y, target: () => [x, y], say, onReach(cop), onFail})` — те же патрульные машины, что и везде |
| Скорая | `createAccident({x, y, kind:'ped', victim: w, medical: true})` — существующая скорая, без ДТП и полиции |
| Проверка каждый кадр | `defWatch(dt => …)` — например, «толкнул прохожего на бегу» |

Запустить вручную в консоли: `startSit('pickpocket')`. Репутация (`player.rep`, −100…100) видна в панели рядом с именем и попадает в подсказку жителям с ИИ.

Сейчас есть:
- `sit-street.js` — карманник, ссора, человеку плохо, кошелёк, собака, уличный музыкант;
- `sit-scam.js` — звонок «из банка» / «следователя» / «Госуслуг», промоутер «бесплатной проверки зрения» с кредитом;
- `sit-transport.js` — оплата проезда и контролёры, забытые в такси вещи, эвакуатор и штрафстоянка (Shift за рулём — «газ в пол»), камеры скорости со штрафом через Госуслуги, объезд перекрытой ДТП улицы;
- `sit-life.js` — работа сменами (💼: бариста, бармен, продавец, офис; опоздание и прогул — выговор, три — увольнение; задания на смене и чаевые), курьер с заказами, аренда и ЖКУ раз в неделю, долг и звонки хозяйки, выселение и новая квартира, простуда под дождём, зонт и аптека, шумные соседи ночью, прорвало трубу;
- `drunk.js` — опьянение и задержание.

## Свой сервер (VPS): онлайн в реальном времени и аккаунты

`server/node/` — сервер на Node.js: раздаёт игру, держит онлайн по WebSocket (позиции и чат мгновенно, соседи до 800 м — 5 раз в секунду), аккаунты «имя + PIN» с сохранением прогресса на сервере (вход с телефона продолжает ту же игру), прокси к ИИ. Понимает и старый протокол `api.php`, так что клиент тот же.

Установка на чистый Ubuntu 22.04/24.04 (2–4 ядра, 4 ГБ). Сначала A-запись домена (например `game.iks-ai-systems.ru`) на IP сервера, потом в консоли сервера:

```bash
curl -fsSL https://raw.githubusercontent.com/itsolutionsirsh-maker/zhivaya-kazan/main/server/node/install.sh -o install.sh
sudo bash install.sh game.iks-ai-systems.ru
```

Скрипт ставит Node.js 20 и Caddy (HTTPS-сертификат сам), запускает службу `zhivaya-kazan` и таймер, который раз в 5 минут подтягивает `main` с GitHub и перезапускает игру, если что-то изменилось. Ключ ИИ — только в `/etc/zhivaya-kazan.env` на сервере (`sudo nano /etc/zhivaya-kazan.env`, затем `sudo systemctl restart zhivaya-kazan`). Журнал: `journalctl -u zhivaya-kazan -f`. Данные аккаунтов: `/var/lib/zk/data/accounts.json`.

Локально: `cd server/node && npm install && GAME_DIR=../../deploy/kazan node server.js` (после `python3 tools/build_deploy.py`).

Пока общие только игроки и чат; жители, машины и ДТП у каждого игрока свои.

### Масштаб: сколько выдержит

Каждому игроку уходят только соседи: радиус 350 м, не больше 80 ближайших (в плотной толпе — 50 и вдвое реже). Имя, одежда и аватар — один раз при появлении, дальше только координаты тех, кто сдвинулся. Остальная толпа приходит числами по клеткам 10×10 м и рисуется точками. Поэтому трафик на игрока не растёт с онлайном.

Замер `server/node/loadtest.js` (2 слабых ядра, сервер и боты на одной машине):

| Онлайн | Из них в толпе на одной площади | Трафик на игрока | Время такта (из 200 мс) |
|---|---|---|---|
| 1 000 | 500 | 4,1 КБ/с | 40 мс |
| 2 000 | 1 400 | 2,4 КБ/с | 65 мс |
| 3 500 | 2 800 | 2,9 КБ/с | 81 мс |

Прикидка на 10 000 одновременно на одной площади: ~30 МБ/с исходящего (~250 Мбит/с) и ~120–150 мс такта на отдельном ядре — одна машина 8 ядер / 16 ГБ / 1 Гбит. Если понадобится больше: вынести сборку сообщений в worker_threads или поделить карту на зоны по процессам. Общий чат при онлайне больше 1 000 слышен в радиусе 1,5 км и не чаще 8 сообщений в секунду на весь город.

### Ответы жителей через ИИ — главный расход

- Модель отвечает, только когда игрок сам заговорил с жителем в окне диалога или обратился вслух по имени/вопросом; остальное — фразы по сценарию.
- Лимиты в `/etc/zhivaya-kazan.env`: `LLM_PER_PLAYER_DAY` (ответов на игрока в день), `LLM_DAILY_LIMIT` (всего в день), `LLM_MAX_TOKENS`. Исчерпан лимит — жители отвечают по сценарию, игра не ломается.
- При большом онлайне выгоднее своя открытая модель на арендованной видеокарте (фиксированная плата вместо оплаты за каждый ответ) — адрес задаётся тем же `LLM_API_BASE`.


## Ритм города

Город живёт по часам (`site/js/rhythm.js`). Число людей на улицах и машин на дорогах идёт по суточной кривой: утренний и вечерний час пик в будни, обед у кафе, к ночи улицы пустеют — люди расходятся по подъездам и заведениям, остаются бары, такси и полиция. В выходные город просыпается позже и дольше гуляет. В дождь людей на улице меньше. День 1 — суббота 20 июня 2026 (та же дата, что у календаря событий).

Заведения работают по часам: кафе примерно с 8 до 22, бары с 16 до 2–6 утра, магазины и аптеки — часть круглосуточно (дежурные аптеки), банки в будни, музеи без понедельника. Закрытое место не пускает: «закрыто · откроется в 8:00». Внутри людей столько, сколько бывает в это время: в обед в кафе полно, ночью пусто, в баре наоборот.

Для других модулей: `poiOpen(poi)`, `opensText(poi)`, `hoursLine(poi)`, `cityWeekday()`, `isWeekend()`, `pedFactor()`, `carFactor()`, `venueBusy(kind)`, `rushHour()`.

## Выложить на свой сайт

```bash
python3 tools/build_deploy.py      # → deploy/kazan.zip
```

Распакуйте `kazan.zip` в корень сайта (получится папка `kazan/`). Нужен PHP 7.4+ с curl. Чтобы жители отвечали «своими словами», скопируйте `config.sample.php` в `config.php` и впишите ключ API (с российского хостинга — через прокси-сервис, адрес в `api_base`). Папка `kazan/data/` должна быть доступна PHP на запись.
