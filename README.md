# Живая Казань

Прототип городской симуляции в духе The Sims на карте реального центра Казани: улицы, дома, остановки и маршруты транспорта из OpenStreetMap, жители‑боты, автобусы по настоящим маршрутам, полиция, скорая, ДТП и живые диалоги с жителями.

## Как устроено

| Папка | Что внутри |
|---|---|
| `site/zhivaya-kazan.html` | Разметка, стили, HUD, модальные окна |
| `site/js/` | Движок по модулям: `rally` (Кремль, площади, митинги, концерты), `talk` (разговор вслух между игроками и с жителями), `companion` (житель выполняет договорённость: идёт с игроком, ведёт в место, заходит внутрь), `transport` (маршрут 🧭: пешком, автобус с пересадкой «сесть/выйти», такси со счётчиком), `situations` + `sit-*.js` (жизненные ситуации, см. ниже), `drunk` (опьянение), `world` (граф, A*, переходы), `agents` (жители, машины, транспорт, ДТП), `vehicles` (самокат, каршеринг, своя машина, вождение), `interior` (интерьеры), `render` (2.5D-отрисовка), `main` (игрок, ввод, диалоги, цикл) |
| `site/js/net.js`, `site/js/chat.js` | Сеть (комната claude.ai или свой сервер `api.php`) и панель чата: Рядом · Город · Личные |
| `server/api.php`, `server/config.sample.php` | Мини-сервер для обычного хостинга (PHP 7.4+): игроки онлайн, общий и личный чат, ответы жителей через OpenAI-совместимый API |
| `server/node/` | Сервер для VPS (Node.js + WebSocket): онлайн в реальном времени, аккаунты и сохранения, установка одной командой |
| `tools/build_deploy.py` | Сборка `deploy/kazan/` и `kazan.zip` для заливки на сайт |
| `tools/dev_build.py`, `tools/smoke_test.py` | Локальная сборка и прогон в headless Chromium |
| `site/kazan.json` | Старая цельная карта центра (≈8,8×9,6 км, без сервера и для локальной проверки; в игре на сервере — карта всей Казани кусками, см. `docs/HANDOFF.md`): дороги с графом, здания, парки, вода, остановки, POI, маршруты. Генерируется из OSM |
| `tools/fetch_tiles.py` | Загрузка OSM плитками 3×3 с перебором зеркал Overpass (`--extras` — докачать стены Кремля и площади) |
| `tools/build_map.py` | Превращает сырые данные в компактный `site/kazan.json` (локальные метры × 10, стыковка маршрутов, обрезка воды) |

Страница не тянет ничего из сети — все данные лежат рядом в `kazan.json`.

## Пересобрать карту

```bash
python3 tools/fetch_tiles.py raw/kazan_v3.json    # вся карта плитками (долго, серверы Overpass часто отвечают 504)
python3 tools/build_map.py raw/kazan_v3.json site/kazan.json
```

Карта: юг 55.752, запад 49.050, север 55.838, восток 49.190 — примерно 8,8 × 9,6 км, от «Яшьлека» и Ново-Савиново на севере до Аметьево и Кабана на юге, от Волги на западе до улиц за парком Горького на востоке (около 15 500 зданий, 21 000 улиц, файл 4,9 МБ, сжатый 1,7 МБ; на слабом телефоне кадров в секунду столько же, памяти +40 МБ). Другой bbox — `BBOX="S,W,N,E"` для обоих скриптов. Расширить уже скачанную карту, докачав только полосы вокруг неё: `BBOX=новый python3 tools/fetch_tiles.py raw/старый.json --ring=старый_S,W,N,E` — плитки по ~1 км, каждая в `raw/ring/`, после обрыва докачиваются только недостающие. Начало координат (lat0/lon0) не меняется, сохранения не сдвигаются.

## Управление

- `WASD` / стрелки — идти, `Shift` — бежать, клик по карте — пойти туда
- `E` — действие: поговорить, зайти в кафе, сесть в автобус
- колесо мыши — масштаб, перетаскивание мышью — двигать карту, `◎` — вернуться к себе
- `🧭` — маршрут: выбрать место (поиск или клик по карте) и как ехать — пешком, автобусом или на такси
- `Enter` / `💬` — чат: Рядом (вслух), Город, Личные
- `Esc` — закрыть окно
- на телефоне: джойстик слева, кнопка действия внизу

## ДТП

На место едут ГИБДД и скорая (с мигалкой им можно против одностороннего движения). Полиция оттаскивает пострадавшего на тротуар и убирает машины к обочине, инспектор отчитывает и штрафует за переход не по зебре (500 ₽, ст. 12.29 КоАП) или оформляет выплату по ОСАГО, если сбили на переходе. Скорая в большинстве случаев лечит на месте — человек идёт дальше по своим делам, в тяжёлых случаях везёт в больницу.

## Кафе, бар и последствия

В кафе и баре есть меню; со спутником можно сесть за один столик и угостить его. Пиво и настойка пьянят (`site/js/drunk.js`): героя шатает, он сам выкрикивает на прохожих, за руль нельзя. Бармен выставляет буяна, прохожие вызывают полицию — ночь в отделе, штраф по ст. 20.21 КоАП.

## Ситуации (жизненные случаи)

Один формат на все случаи — движок `site/js/situations.js`. Ситуация описывается одним объектом и регистрируется через `defSit`:

```js
defSit('wallet', {
  title: 'Кошелёк', auto: true, weight: 2, cool: 600,   // случайный запуск: вес и пауза до повтора (с)
  when()   { return scene === 'city' && !player.vehicle; },  // где и когда может случиться
  start(s) { /* участники, метки, карточка */ return true; }, // false — не получилось, ничего не запускаем
  update(s, dt) { /* каждый кадр; endSit(s) — конец */ },
  action(s) { return near ? {label: 'Поднять кошелёк', run} : null; },  // кнопка E на улице
  actionInside(s) { /* кнопка E в помещении */ },
  draw(s, toS, z) { /* своё рисование на карте */ },
  ctx(s, w) { return 'Ты только что потерял кошелёк…'; },   // подсказка жителю с ИИ, если с ним заговорить
});
```

Готовые помощники:

| Что | Функция |
|---|---|
| Карточка с 2–3 ходами (клавиши 1–3) | `sitCard({s, icon, title, text, choices:[{t, run, primary}], ttl, onTimeout, tone:'alert'\|'good'\|'call'})` |
| Последствия | `sitMoney(±₽, 'за что')`, `sitRep(±, 'за что')`, `sitMood(±)`, `dossier('запись в полиции')`, `remember(житель, 'что он запомнит')` |
| Отложенное последствие | счётчик в `s` и проверка в `update` (пример — «Оставить кошелёк себе» → звонок участкового через 1,5–3 мин) |
| Участники | `findWalker(minR, maxR)`, `takeActor(s, w)` (житель занят ситуацией), `moveActor(w, x, y, скорость)` + `stepActor(w, dt)`, `faceTo`, `say(w, 'реплика')` |
| Метки на карте | `mark(s, key, x, y, '🙋', 'подпись', {arrow:true})`, `unmark(key)` |
| Полиция | `callPatrol({x, y, target: () => [x, y], say, onReach(cop), onFail})` — те же патрульные машины, что и везде |
| Скорая | `createAccident({x, y, kind:'ped', victim: w, medical: true})` — существующая скорая, без ДТП и полиции |
| Проверка каждый кадр | `defWatch(dt => …)` — например, «толкнул прохожего на бегу» |

Запустить вручную в консоли: `startSit('pickpocket')`. Репутация (`player.rep`, −100…100) видна в панели рядом с именем и попадает в подсказку жителям с ИИ.

Сейчас есть:
- `sit-street.js` — карманник, ссора, человеку плохо, кошелёк, собака, уличный музыкант;
- `sit-scam.js` — звонок «из банка» / «следователя» / «Госуслуг», промоутер «бесплатной проверки зрения» с кредитом;
- `sit-transport.js` — оплата проезда и контролёры, забытые в такси вещи, эвакуатор и штрафстоянка (Shift за рулём — «газ в пол»), камеры скорости со штрафом через Госуслуги, объезд перекрытой ДТП улицы;
- `sit-life.js` — работа сменами (💼: бариста, бармен, продавец, офис; опоздание и прогул — выговор, три — увольнение; задания на смене и чаевые), курьер с заказами, аренда и ЖКУ раз в неделю, долг и звонки хозяйки, выселение и новая квартира, простуда под дождём, зонт и аптека, шумные соседи ночью, прорвало трубу;
- `drunk.js` — опьянение и задержание.

## Свой сервер (VPS): онлайн в реальном времени и аккаунты

`server/node/` — сервер на Node.js: раздаёт игру, держит онлайн по WebSocket (позиции и чат мгновенно, соседи до 800 м — 5 раз в секунду), аккаунты «имя + PIN» с сохранением прогресса на сервере (вход с телефона продолжает ту же игру), прокси к ИИ. Понимает и старый протокол `api.php`, так что клиент тот же.

Установка на чистый Ubuntu 22.04/24.04. Для старта хватает 1 ядра и 1 ГБ памяти (скрипт сам добавит подкачку на 1 ГБ); для большого онлайна — 2–4 ядра, 4 ГБ. Сначала A-запись домена (например `game.iks-ai-systems.ru`) на IP сервера — или, пока домена нет, адрес вида `203-0-113-7.sslip.io` (IP через дефисы, запись не нужна). Потом в консоли сервера:

```bash
curl -fsSL https://raw.githubusercontent.com/itsolutionsirsh-maker/zhivaya-kazan/main/server/node/install.sh -o install.sh
sudo bash install.sh game.iks-ai-systems.ru
```

Скрипт ставит Node.js 22 и Caddy (HTTPS-сертификат сам), открывает в брандмауэре только SSH, 80 и 443, запускает службу `zhivaya-kazan` и таймер, который раз в 5 минут подтягивает `main` с GitHub и перезапускает игру, если что-то изменилось. Ключ ИИ и токен бота — только в `/etc/zhivaya-kazan.env` на сервере (`LLM_API_KEY`, `TG_BOT_TOKEN`; `sudo nano /etc/zhivaya-kazan.env`, затем `sudo systemctl restart zhivaya-kazan`). Сменить домен — запустить `install.sh` ещё раз с новым доменом. Можно сразу несколько адресов: `sudo bash install.sh kazan.lifegorod.com 213-218-161-82.sslip.io` — первый основной (кнопка в боте), второй работает, пока основной домен ещё не активен. В веб-консоли noVNC хостинга не набираются символы с Shift (`:`, `&`, `|`), поэтому там адрес пишется без `https://`, а команды — по одной. Журнал: `journalctl -u zhivaya-kazan -f`. Данные аккаунтов: `/var/lib/zk/data/game.db` (SQLite).

Локально: `cd server/node && npm install && GAME_DIR=../../deploy/kazan node server.js` (после `python3 tools/build_deploy.py`).

Переезд с PHP-хостинга (аккаунты, ключи входа, привязки Телеги и приглашения переносятся, игроки ничего не замечают). На старом хостинге должен стоять свежий `api.php` (в нём `a=export`), токен бота на обоих серверах одинаковый — им подписан ключ выгрузки:

```bash
sudo -u zk bash -c 'set -a; . /etc/zhivaya-kazan.env; cd /opt/zhivaya-kazan/server/node && node server.js --import-php https://iks-ai-systems.ru/kazan/api.php'
```

Повторный запуск безопасен: аккаунт перезаписывается, только если на старом хостинге он новее. PIN со старого хостинга (bcrypt) принимается, после первого входа переводится на scrypt.

Пока общие только игроки и чат; жители, машины и ДТП у каждого игрока свои.

### Масштаб: сколько выдержит

Каждому игроку уходят только соседи: радиус 350 м, не больше 80 ближайших (в плотной толпе — 50 и вдвое реже). Имя, одежда и аватар — один раз при появлении, дальше только координаты тех, кто сдвинулся. Остальная толпа приходит числами по клеткам 10×10 м и рисуется точками. Поэтому трафик на игрока не растёт с онлайном.

Замер `server/node/loadtest.js` (2 слабых ядра, сервер и боты на одной машине):

| Онлайн | Из них в толпе на одной площади | Трафик на игрока | Время такта (из 200 мс) |
|---|---|---|---|
| 1 000 | 500 | 4,1 КБ/с | 40 мс |
| 2 000 | 1 400 | 2,4 КБ/с | 65 мс |
| 3 500 | 2 800 | 2,9 КБ/с | 81 мс |

Прикидка на 10 000 одновременно на одной площади: ~30 МБ/с исходящего (~250 Мбит/с) и ~120–150 мс такта на отдельном ядре — одна машина 8 ядер / 16 ГБ / 1 Гбит. Если понадобится больше: вынести сборку сообщений в worker_threads или поделить карту на зоны по процессам. Общий чат при онлайне больше 1 000 слышен в радиусе 1,5 км и не чаще 8 сообщений в секунду на весь город.

### Ответы жителей через ИИ — главный расход

- Модель отвечает, только когда игрок сам заговорил с жителем в окне диалога или обратился вслух по имени/вопросом; остальное — фразы по сценарию.
- Лимиты в `/etc/zhivaya-kazan.env`: `LLM_PER_PLAYER_DAY` (ответов на игрока в день), `LLM_DAILY_LIMIT` (всего в день), `LLM_MAX_TOKENS`. Исчерпан лимит — жители отвечают по сценарию, игра не ломается.
- При большом онлайне выгоднее своя открытая модель на арендованной видеокарте (фиксированная плата вместо оплаты за каждый ответ) — адрес задаётся тем же `LLM_API_BASE`.


## Ритм города

Город живёт по часам (`site/js/rhythm.js`). Число людей на улицах и машин на дорогах идёт по суточной кривой: утренний и вечерний час пик в будни, обед у кафе, к ночи улицы пустеют — люди расходятся по подъездам и заведениям, остаются бары, такси и полиция. В выходные город просыпается позже и дольше гуляет. В дождь людей на улице меньше. День 1 — суббота 20 июня 2026 (та же дата, что у календаря событий).

Заведения работают по часам: кафе примерно с 8 до 22, бары с 16 до 2–6 утра, магазины и аптеки — часть круглосуточно (дежурные аптеки), банки в будни, музеи без понедельника. Закрытое место не пускает: «закрыто · откроется в 8:00». Внутри людей столько, сколько бывает в это время: в обед в кафе полно, ночью пусто, в баре наоборот.

Для других модулей: `poiOpen(poi)`, `opensText(poi)`, `hoursLine(poi)`, `cityWeekday()`, `isWeekend()`, `pedFactor()`, `carFactor()`, `venueBusy(kind)`, `rushHour()`.

## Свои люди

Восемь постоянных жителей (`site/js/folk.js`, список и характеры — `people.js` второго программиста) живут по распорядку: дом → работа → своё место → дом. Алсу стоит за стойкой бара на Баумана, Ленар играет на гитаре на Баумана, Гульнара работает в аптеке у вашего дома, соседка Фидания сидит во дворе, Зульфия после уроков гуляет у Кремля, Ринат готовит в кафе у площади Свободы, Марат днём за рулём такси, вечером в чайхане. Когда вы рядом, они идут по улицам своими маршрутами; когда далеко — просто перемещаются по расписанию.

После первого разговора они вас узнают: здороваются раз в день, над головой видно имя со звёздочкой, ИИ получает их характер и сколько раз вы виделись. Память разговоров сохраняется между заходами.

Для других модулей: `cityFolkWhere(id)` — где сейчас человек (`{text, place, at, known}`), `cityFolkAll()` — все сразу.

## Свой район

В анкете есть «Где живёте»: центр у Баумана или один из жилых районов `districts.js` (Азино, Аметьево, Савиново, Соцгород…, по административным районам). Новый игрок начинает во дворе жилого дома своего района, этот дом становится его домом, жители, машины и соседи по двору (Марат, Гульнара, Фидания) — рядом. Дом запоминается в сохранении; смена района в анкете — переезд. Точка двора — из `site/js/home-spots.js` второго программиста (`window.cityHomeSpots`, `district` — id жилого района), а пока для района точки нет (или она дальше 2,5 км от центра района — значит, ошибка в данных) — центр района из `districts.js`, от него ближайший жилой дом (`settleInDistrict` в `main.js`).

## Банк, машина и деньги за день

`site/js/bank.js`. Деньги игрока — на карте. В отделении банка (окно операциониста, в будни днём) и в банкомате у входа в любое время:

- **вклад** под 16% годовых — проценты капают каждое утро;
- **кредит** 10 или 30 тысяч на 30 дней под 28%: платёж списывается каждое утро. Если денег не хватает, начисляются пени, а после трёх дней просрочки звонят из банка. С плохой репутацией или долгами банк откажет;
- **ОСАГО** (8 500 ₽ в год) и **КАСКО** (32 000 ₽).

Своя машина после ДТП: она теряет 25–45% состояния и при износе ниже 50% едет медленнее, а ниже 12% не заводится (тогда вызывают эвакуатор и делают ремонт). Если виноваты вы и ОСАГО нет, ущерб второй машине (18–45 тыс.) или компенсацию пешеходу (30 тыс.) платите сами, плюс штраф 800 ₽ по ст. 12.37. Если денег не хватает, остаток становится долгом по суду, и приставы каждое утро списывают половину денег с карты. Если виноват другой водитель, ремонт оплатит его страховая. Ремонт делают в автосервисе на АЗС. За ДТП по вашей вине на каршеринге списывается франшиза 15 000 ₽.

Каждое утро банк присылает сводку «вчера: доход / расходы / на карте». Зарплата, штрафы, аренда и коммуналка тоже приходят сообщениями в телефон (`cityPhone.push`), а если телефона нет — в ленту событий.

## Метро

На карте всей Казани — все 11 станций первой линии, от Авиастроительной до Дубравной; на старой карте центра (`site/kazan.json`) — шесть: Яшьлек, Козья слобода, Кремлёвская, Площадь Тукая, Суконная слобода, Аметьево (входы — из OSM, `railway=subway_entrance`).

`site/js/metro.js`. В Казани одна линия метро (11 станций, вторая линия строится). В старую карту центра попадают шесть станций: **Яшьлек**, **Козья слобода** (за Казанкой), **Кремлёвская** (у Кремля и начала Баумана), **Площадь Габдуллы Тукая** (конец Баумана, «Кольцо»), **Суконная слобода** и **Аметьево**. У входов на карте стоит красный знак «М».

Как ездить: вход 46 ₽ через турникет, на платформе подойти к краю и выбрать станцию. Поезд приходит через 5 минут в час пик, через 8 днём и через 12 вечером. Время в пути: Яшьлек → Козья слобода 2,5 мин, Козья слобода → Кремлёвская 2,5 мин, Кремлёвская → Тукая 2 мин, Тукая → Суконная слобода 2,5 мин, Суконная слобода → Аметьево 2 мин. В поезде объявляют следующую станцию по-русски и по-татарски, потом вы выходите на улицу у нужной станции. Метро работает с 6:00 до полуночи. ## Мини-приложение в Телеге

Та же игра по тому же адресу (`https://iks-ai-systems.ru/kazan/`), открытая из бота. `site/js/tg.js` срабатывает, только если игра открыта из Телеги: игра разворачивается на весь экран, свайп вниз её не закрывает, кнопка «Назад» Телеги закрывает окна, а имя из Телеги подставляется в анкету персонажа.

Вход: Телега передаёт `initData`, подписанный ботом. Сервер (`api.php` → `tglogin`, на VPS — то же в `server.js`) проверяет подпись (HMAC-SHA256, ключ — HMAC «WebAppData» от токена бота), не принимает данные старше суток и выдаёт ключ аккаунта. Прогресс лежит на сервере: деньги, место, работа, банк, знакомые, записки и телефон (`zk.state` + `zk.profile` + `zk.citylife`). Открыл с другого телефона — продолжаешь с того же места.

Если игрок уже играл на сайте под именем с PIN, в меню Телеги можно «Привязать» этого игрока (`tglink`), и дальше Телега будет открывать его. «Начать заново» с двойным нажатием стирает только свой прогресс (здесь и на сервере), имя и вход остаются.

Аккаунты по имени и PIN теперь работают и на Beget: `api.php` хранит их в `data/acc`, `data/tok`, `data/tgm`.

Бот — **@zhivaya_kazan_bot**, мини-приложение — `https://t.me/zhivaya_kazan_bot/game`, кнопка меню «Играть» (подробности — `docs/TELEGRAM.md`). На `/start` бот отвечает приветствием с кнопкой «Играть»: вебхук на `api.php?a=tgwebhook` сервер ставит сам: PHP — когда в `config.php` появляется токен, VPS (`server.js`) — при запуске, если в `/etc/zhivaya-kazan.env` есть `TG_BOT_TOKEN` и `PUBLIC_URL` (заодно ставит кнопку меню на этот адрес). Ответ на `/start` уходит прямо в ответе на вебхук, поэтому серверу не нужен исходящий доступ к api.telegram.org — только сам вебхук. Запросы проверяются секретом, производным от токена; если вебхук уже смотрит на другой сервер, PHP его не перебивает. При первом запуске в Телеге — три коротких экрана-подсказки. В меню «Позвать друга» отправляет ссылку `…/game?startapp=ref_<id>`: новичок и тот, кто позвал, получают запись и немного настроения (или карточку из `people.js`, если там есть `window.cityOnInvite(kind, name)`).

Что нужно от владельца: создать бота у @BotFather, сделать мини-приложение (`/newapp`) с адресом игры, а токен бота вписать самому в `config.php` на сервере (`'tg_bot_token' => '...'`). На VPS токен пишется в `TG_BOT_TOKEN` в `/etc/zhivaya-kazan.env`.

## Модерация

Фильтр — `site/js/modcore.js`, один файл и для игры, и для сервера. Он прячет мат звёздочками (учитывает приставки и подмену букв: «xyй», «6ля»), ссылки, @ники и телефоны. Сплошной крик заглавными приводит к строчным. Работает в общем чате, личных сообщениях, репликах над головой, на табличках митингов и в выступлениях. Имя с матом или ссылкой другие видят как «Игрок», а в анкете такое имя не принимается.

У игрока (`site/js/moderation.js`): нажать на имя в чате → «Скрыть игрока» (его сообщения и реплики больше не видны, список — в меню ☰) или «Пожаловаться». Одно и то же сообщение подряд отправить нельзя. Правила — строкой вверху общего чата.

На сервере (`server.js`):
- **Жалобы** пишутся в `/var/lib/zk/data/reports.jsonl`.
- **Автоотключение:** три жалобы от разных людей за час — общий чат нарушителю отключается на час.
- **Страница модератора** `https://<домен>/mod.html` с ключом модератора: его показывает страница `/setup` после сохранения, а ещё бот присылает его владельцу по команде `/key` (только тому, чей id указан на `/setup`). Ключ лежит в `/var/lib/zk/data/secrets.json`. На ней жалобы, кто в игре, отключить чат на час, забанить на сутки или навсегда (по игроку и его IP), снять бан. Баны хранятся в `data/mod.json`.

На PHP-хостинге жалобы копятся в `data/reports.php`, автоотключения и страницы модератора там нет.

## Цифры, копии базы и «сервер жив» (VPS)

- **Цифры по дням** — на той же странице `mod.html`: сколько игроков за день, сколько новых, какая доля новичков вернулась на 2-й день и через неделю, откуда пришли (Телега, ссылка друга, метка `?from=vk` в адресе, сайт-источник). Сервер пишет только случайный номер устройства и день (таблицы `visits`, `firsts` в `game.db`), без имён и IP. Сутки — по Москве.
- **Копия базы** — каждый день в 4 утра по Москве в `/var/lib/zk/data/backup/` (база, баны, жалобы), хранится 7 дней. `BACKUP_TO_TG=1` в `/etc/zhivaya-kazan.env` — копия ещё и приходит админу в Телегу (сжатая, до 45 МБ).
- **Сводка в 9 утра** админу в Телегу: игроки за вчера, возврат на 2-й день и через неделю, пик онлайна, ответы ИИ.
- **«Сервер жив»** — `zk-health` (таймер раз в 2 минуты): две проверки подряд без ответа — перезапуск службы и сообщение в Телегу; диск заполнен больше чем на 90% — предупреждение раз в день.

Для сводки и тревог нужен `ADMIN_TG_ID` — ваш числовой id в Телеге (его покажет бот @userinfobot) и `TG_BOT_TOKEN`; сначала напишите своему боту `/start`, иначе Телега не даст ему писать вам. Скрипты, которые работают от root (`zk-update`, `zk-health`), `install.sh` кладёт в `/usr/local/sbin`, вне папки игры; после их правки — снова `sudo bash install.sh <домен>`.

## Выложить на свой сайт

```bash
python3 tools/build_deploy.py      # → deploy/kazan.zip
```

Распакуйте `kazan.zip` в корень сайта (получится папка `kazan/`). Нужен PHP 7.4+ с curl. Чтобы жители отвечали «своими словами», скопируйте `config.sample.php` в `config.php` и впишите ключ API (с российского хостинга — через прокси-сервис, адрес в `api_base`). Папка `kazan/data/` должна быть доступна PHP на запись.
