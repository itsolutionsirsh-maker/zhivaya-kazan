# Метро: татарские названия и объявления

Сверка для `metro.js`. В игре названия не менял: правку вносит первый программист.

Источник таблицы: [список станций](https://ru.wikipedia.org/wiki/Список_станций_Казанского_метрополитена), татарское имя в скобках как на странице. Второй источник, где он расходится: [статья «Казанский метрополитен»](https://ru.wikipedia.org/wiki/Казанский_метрополитен).

| Станция | Сейчас в metro.js | По списку станций | Что поправить |
|---|---|---|---|
| Авиастроительная | Авиатөзелеш | Авиатөзелеш | нет |
| Северный вокзал | Төньяк вокзал | Төньяк вокзалы | да, на конце «ы» |
| Яшьлек | Яшьлек | Яшьлек | нет |
| Козья слобода | Кәҗә бистәсе | Кәҗә бистәсе | нет |
| Кремлёвская | Кремль | Кремль | нет |
| Площадь Габдуллы Тукая | Габдулла Тукай мәйданы | Габдулла Тукай Мәйданы | в списке «М» большое |
| Суконная слобода | Суконная бистәсе | Сукно бистәсе | в `main` уже стоит «Сукно бистәсе», на `city-week` подтянется слиянием |
| Аметьево | Әмәт | Әмәт | нет |
| Горки | Горки | Горки | нет |
| Проспект Победы | Җиңү проспекты | Җиңү проспекты | нет |
| Дубравная | Дубравная | Дубравная | см. ниже |

«Дубравная». Список станций и статья самой станции пишут тат. «Дубравная». В обзорной статье метро стоит другое: тат. «Имәнлек». На табличку я не смотрел. Пока оставляй «Дубравная», «Имәнлек» не подставляй, пока не сверишь вывеску.

Объявления. Запись 2013 года, женский голос, север → юг, сайт «Мир метро»: [звуки казанского метро](https://mirmetro.net/articles/zvuki-kazanskogo-metro).

- Русский, двери и следующая: «Осторожно, двери закрываются, следующая станция – «Северный вокзал».»
- Татарский: «Сак булыгыз! Ишекләр ябыла, киләсе тукталыш - «Төньяк вокзал» станциясе.»
- Русский, конечная: «Станция «Авиастроительная». Конечная. Уважаемые пассажиры, просьба освободить вагоны.»
- Татарский в той же записи на конечной короткий: ««Авиатөзелеш» станциясе.»

В разговоре на «Северном вокзале» в записи нет «ы» («вокзал»), в списке станций есть («вокзалы»). Для таблички бери список, для голоса в вагоне — фразу с записи.
