# Первое знакомство: Амина и фотографии двора

Передача от 31.10.2026. База: `main` на `772b6d6`, ветка `dev3/first-neighbor`.

## Что изменилось

Новичок получает короткую историю после восьми активных секунд вне стартовых окон. Амина просит собрать разлетевшиеся фотографии или закрепить стенд. Игрок выбирает помощь, возвращается, видит восстановленный стенд и получает приглашение встретиться снова. На следующий московский календарный день Амина помнит выбор и предлагает тему следующей выставки: люди или места.

Можно отказаться или продолжить позже. Цель подключена через `cityObjectives.register`. Во время активной встречи рядом с ней случайные автособытия, столкновения-ссоры и запуск истории с мошенником временно уступают место знакомству. После завершения, отказа или откладывания обычные цели продолжаются. Старые сохранения не получают вступление заново.

Это личная история и личный стенд, не общий сетевой двор. Состояние хранится в `PROG.firstNeighbor` и существующем снимке аккаунта. Денежных наград и новых серверных маршрутов нет. `server.js`, роли, бариста и кошелёк не менялись.

## Проверки

- `node --test --test-isolation=none tools/tests/*.test.js`: 323/323 успешно, включая три новых теста переходов и сохранения выбора.
- Локальная сборка открыта в браузере: обе ветки, движение по построенному пешеходному маршруту, возвращение, повторная встреча на следующий день, сохранение после перезагрузки и запись/чтение через настоящий локальный API аккаунта проверены.
- Снимки интерфейса: 360×640, 390×844, 844×390, 1280×800. Отдельно результат и повторная встреча на 390 px.
- Для ускорения ручного прохождения использовались локальные тестовые кнопки продвижения времени и движения через существующие функции игры. Это не замер длительности первого прохождения живым игроком. Тестовая панель и база аккаунта в патч не входят.
- Полный автоматический браузерный прогон и `perf.js` НЕ завершены: отсутствует Chromium Playwright, установка останавливается на `spawn EPERM`. Числа производительности не заявляются. Проверка физических телефонов, Telegram и всех стартовых районов остаётся за принимающим инженером.

## Приёмка перед слиянием

В архиве приложен единый `first-neighbor.patch`. Применить на отдельной ветке от актуального `main`, предварительно выполнив `git apply --check first-neighbor.patch`. На базе `772b6d6` патч проверяется отдельно. При изменившемся `main` проверить точки интеграции в `story.js`, `situations.js`, `sit-street.js` и HTML.

Собрать рабочую версию штатным `tools/dev_build.py` с картой, установить зависимости и браузер Playwright. Затем:

```sh
node --test tools/tests/*.test.js
node tools/tests/first-neighbor-browser.js <build-after> <shots-dir> 8999
node tools/tests/perf.js <build-main> <build-after>
```

Также выполнить штатную браузерную матрицу проекта. Новый браузерный тест содержит обе ветки, отказ, перезагрузку, маршруты, четыре размера экрана, повторную встречу и сохранение аккаунта, но его автоматический PASS в этой среде не получен.

На GitHub ветка не опубликована и PR не создан: создание ветки через подключение вернуло HTTP 403 `Resource not accessible by integration`. На рабочем сайте изменений нет. Передача архивом предназначена для проверки и PR принимающим инженером, не для прямой замены файлов работающего сайта.
