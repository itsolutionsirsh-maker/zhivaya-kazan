# Проверка проекта (25–26.10.2026)

Что нашли при полной проверке, что уже исправлено и что осталось. Каждую находку воспроизвели (на локальном сервере или в браузере без экрана), а не только прочитали в коде.

## Сервер (`server/node/server.js`)

| Важность | Что было | Статус |
|---|---|---|
| критично | Один POST с телом `null` (числом, массивом) ронял весь процесс: ошибка в async-обработчике не ловилась, Node завершался, вылетали все игроки; повтор — сервер лежит постоянно | исправлено (`00eb394`): тело — только объект, ошибка обработчика — ответ 500, необработанные ошибки — в журнал |
| высокая | Номер игрока из браузера рассылался соседям; зная его, можно было войти под чужим номером, читать чужие личные и писать от чужого имени | исправлено (`7184abb`): соседям виден только публичный номер (хэш), клиент узнаёт свой из ответа сервера |
| высокая | Имя `tg:<id>` при входе по имени и PIN занимало ключ аккаунта Телеги — владелец Телеги потом получал чужой аккаунт, а захватчик читал его прогресс | исправлено: имена с «:» запрещены, аккаунт `tg:<id>` не от Телеги владельцу не отдаётся |
| высокая | Несколько `hello` в одном соединении создавали «призраков», которых никто не убирал: один клиент мог занять всю память и такт | исправлено: одно соединение — один игрок |
| средняя | Все лимиты «по IP» обходились подставным `X-Forwarded-For` (бралось первое значение) — бесконечное создание аккаунтов, обход лимита ИИ | исправлено: заголовок — только от Caddy с этой машины, последний адрес |
| средняя | Лимит ИИ на игрока считался по номеру, который клиент меняет сам — один человек мог сжечь дневной бюджет ИИ (счёт у провайдера) | исправлено: ещё и лимит на адрес; дальше — считать по аккаунту |
| средняя | Оборванная загрузка файла (карта, скрипты) не закрывала файл — копились дескрипторы и память | исправлено |
| средняя | Поток новых номеров раздувал таблицы посещений и ежедневные копии базы | исправлено: не больше 30 новых номеров в час с адреса |
| средняя | Занятая база (во время копии) — сохранение молча терялось, ответа не было | исправлено: `busy_timeout`, при ошибке — `{err:'busy'}` |
| средняя | Таймер обновления раз в 5 минут перезапускает игру посреди сборки карты и отдачи файлов | осталось: отдавать игру из готовой папки сборки с атомарной подменой, не перезапускать во время сборки (`update.sh` ставится через `install.sh` — нужен его повторный запуск) |
| низкая | Вход на сайте через бота: чужую ссылку можно подсунуть | смягчено: бот показывает устройство и время и прямо предупреждает о чужой ссылке |
| низкая | `reports.jsonl` растёт без ротации | осталось |

Проверено и в порядке: защита от выхода за папку игры (`../`, `%00`), подпись Телеги (`initData`), секрет вебхука, страница `/setup` (без мод-ключа её не перехватить), мод-ключ, PIN (scrypt, блокировка после 8 ошибок), пределы размеров запросов и сообщений, права на `secrets.json`, новые вход с сайта и замер загрузки.

**Срочно — дело владельца:** токен бота попадал в чат — перевыпустить его у @BotFather и ввести на `/setup#change` (от токена зависят и секрет вебхука, и ключ выгрузки со старого хостинга). На старом хостинге (Бегет) удалить `api.php` и папку `data/` — там могут оставаться аккаунты.
