# Живая Казань — вход для нового программиста

Городская симуляция на настоящей карте Казани (OpenStreetMap): жители-боты со своим распорядком, машины, автобусы, трамваи и метро, ДТП со скорой и ГИБДД, кафе и квартиры внутри, работа, банк, задания дня, сезон, онлайн с чатом. Работает в браузере и мини-приложением в Телеге. Владелец проекта — Иршат.

## Как устроено — коротко

- **Клиент** — `site/zhivaya-kazan.html` (разметка, стили, окна) и `site/js/*.js`: обычные скрипты без сборщика, общие глобальные переменные, порядок подключения — внизу html. Рисование — canvas 2.5D (`render.js`), мир и граф улиц — `world.js` (типизированные массивы), подгрузка карты кварталами 2×2 км — `chunks.js`, жители и машины — `agents.js`, `vehicles.js`, распорядок дня — `rhythm.js`, задания, значки, вечера — `engine.js`, сезон и вещи — `season-run.js`, прокурор — `prosecutor.js`, сеть и аккаунты — `net.js`, ситуации — `situations.js` и `sit-*.js`.
- **Данные второго программиста** (только данные, без кода): `daily.js`, `quests.js`, `shop.js`, `season.js`, `districts.js`, `landmarks.js`, `home-spots.js`, `folk2.js`, `tutorial.js`, `people.js`, `phone.js`, `events.js`, `fixtures.js`, `roles.js`, `city-people.js`, `city-texts.js` (из них в игре пока прокурор). Только в ветке `city-week`, ещё не в игре: `gossip.js`, `paper.js`, `weather-lines.js`, `lang-tt.js` (татарский не вычитан носителем).
- **Сервер** — `server/node/server.js` (Node 22, без фреймворка; `ws`, `bcryptjs`, `node:sqlite`): раздаёт игру и карту, онлайн по WebSocket, чат, аккаунты (имя + PIN, вход через Телегу), сохранения, бот, модерация, ответы жителей через ИИ. Стоит на VPS за Caddy.
- **Карта** — `tools/fetch_city.py` качает OSM плитками по границе города, `tools/build_city.py` собирает `base.json` (крупные улицы, транспорт, важные места) и кварталы `c_x_y.json`. Собирается на сервере; в репозитории — только старая карта центра `site/kazan.json` для локальной проверки.

## Запустить у себя

```bash
git clone https://github.com/itsolutionsirsh-maker/zhivaya-kazan && cd zhivaya-kazan
python3 tools/dev_build.py /tmp/zk-dev && cd /tmp/zk-dev && python3 -m http.server 8000
# http://localhost:8000/index.html — карта центра, без онлайна и аккаунтов
```

С настоящим сервером (онлайн, аккаунты, карта кусками) и проверками в браузере — `tools/tests/README.md`.

## Как выкатывается

`main` → сервер сам раз в 5 минут забирает свежий `main`, собирает и перезапускает игру. Поэтому **в `main` попадает только проверенное**.

## Как работаем

- **Код игры** (`site/js` кроме файлов данных, `site/zhivaya-kazan.html`, `server/`, `tools/`) ведёт первый программист (Claude Code по поручению Иршата) — сразу в `main`.
- **Данные** — второй программист, в ветке `city-week`; задания и отчёты — `docs/SYNC.md` в той же ветке (только дописывать в конец).
- **Третий программист (Codex) — графика и удобство:** своя ветка от свежего `main` на каждую задачу (`dev3/<коротко-о-чём>`), затем pull request в `main` со снимками до/после и цифрами скорости. Перед слиянием первый программист проверяет и прогоняет проверки, Иршат говорит «да». В `main` напрямую не пушить. **Чьи файлы сейчас и задание на первый пакет — `docs/DEV3.md`.**
- **Ключи, пароли, токены** в чат и в код не пишем. Их вводит Иршат сам: `/setup` на сайте, @BotFather, панели хостинга. Доступ к самому серверу для работы не нужен — всё выкатывается через `main`.
- Мэр, полиция и прочие городские персонажи — **вымышленные**, без политики и без реальных людей. Мата в игре нет (она в Телеге и в каталогах, играют и дети).
- Тексты для игрока — по-русски, коротко; Иршату отвечаем по-русски, коротко.
