# Городская газета «Вечерняя Казань»

Правила тона для выпусков:

- Без насмешек над игроками.
- Без политики.
- Имена только с согласия (или вымышленные).
- Факты короткие, без сенсаций.
- Погода и события — нейтрально.

Подсказка для ИИ, который будет писать выпуск:

Пиши короткие заметки по шаблонам из paper.js. Используй подстановки {name}, {street}, {place}, {n}. Тон спокойный, как у местной газеты. Не придумывай скандалы. Если нет данных — пропускай рубрику.
